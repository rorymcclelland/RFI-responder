# Risk register

Owner of every risk: Rory McClelland (product owner). Reviewed at each sprint close. Last check: 25 October 2026, Sprint 7 close (evidence: CI on `sprint-7`, 545 unit and 227 database tests, the independent security review of Sprint 7 with all seven findings fixed, a scan of the full git history, and the end-to-end export check on the local PC).

Likelihood and impact are judged for a real organisation using the tool as designed (low, medium, high). **Residual** is what is left after the controls. A control marked **planned** is not built yet. The "Tests" column lists the files that prove each control; `docs/governance/governance.test.ts` fails if any of them is missing.
